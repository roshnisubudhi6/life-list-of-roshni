# Life list of Roshni

My birding life list: every species I've seen, painted in the spirit of Monet's *Water Lilies*, with my own photos, sighting dates and places.

- `index.html` is the whole site: page, styles, painted-bird code and the bird data.
- `photos/` holds my photos, named after each bird.

Open `index.html` in a browser, or publish the repo with GitHub Pages (Settings → Pages → Deploy from branch → `main`, folder `/`).

Note: adding and editing birds works only on the claude.ai version of the site. This copy is view-only.
